Privacy

No account, no sign-up, no cookies. You never tell this site who you are, and it never asks.

Your streak and scores stay on this device. They live in your browser's own storage and are never sent anywhere. Clear your browser data and they are gone — which is why the stats screen offers a restore code you can copy somewhere safe. That code is yours; nothing about it is stored here.

Anonymous usage counts. This site uses Umami, a cookieless analytics tool, to count things like how many people start a round, which question they were on when they stopped, and what score bands come up. It records no cookies and no IP addresses, and there is no identifier that links one visit to another. Nobody can be picked out of it, including by me.

What is never collected. Your name, your email, your location beyond the country a request arrives from, or anything you type. When you add a name to a challenge link, that name is put in the link you send and is removed from the address bar the moment the page opens — it is not sent to the analytics tool. It does travel to the web host as part of the link, where it may appear briefly in routine server logs, the same as any web address.

Where it is hosted. Cloudflare serves the site and the questions, and keeps standard access logs. Umami Cloud holds the anonymous counts above.

Children. This is a sports trivia game, not aimed at children, and it collects nothing that would identify anyone of any age.

Questions: the whole site is open source — you can read exactly what it collects rather than take my word for it.
